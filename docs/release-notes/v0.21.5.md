## v0.21.5

書き換えの照合（`compare_rewrite.py`）の「表現の種類」に、許可・未定の状態・因果の接続を足した（#141）。

### 追加

- `permission`: 「してよい」「しても構わない」「許可されている」などの許可の言い方が、対応する文のあいだで増えた、または減った。
- `status`: 「未定」「調査中」「検討中」「保留」「まだ〜ない」などの、決まっていない・分かっていない状態の語が増減した。
- `causal`: 「した結果、」「ことで」「ため、」「ので、」などの因果の接続が増減した。「ことである」「ことでは」は数えない。
- 判定ではなく情報である。

### 実測（#141）

- リポジトリの Markdown 56 ファイル、5,616 文で、各型を含む文の割合は permission 0.7%、status 1.5%、causal 2.7%。
- 意味が変わる合成の 13 組（作者が作った例）はすべて挙がった。偏りがあるので、実際の書き換えでの再現率は未測定。
- 意味を保つ合成の 6 組のうち、3 組は挙がらなかった（「未定である → 未定です」、「ため、…遅れた → …遅れました」、「ため → ので」）。挙がった 3 組は、「してよい → 問題ない」（許可の語が消えた）、「調査中 → 調べている」（状態の語が消えた）、「削除により → 削除したことにより」（因果の語が増えた）で、書き方が変わった箇所を示す候補になる。
- 既存の fixtures の書き換え 4 組は 0 件。

### 限界

- 語の一覧による近似で、同義語は見逃す。「ため」は目的の意味でも数える。
- 実際の書き換えのペアでの誤検出の率は測っていない。
