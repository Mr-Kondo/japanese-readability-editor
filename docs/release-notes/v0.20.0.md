## v0.20.0

フィードバック票と、使った後の変化の記録を、スクリプトの実行時に自動保存するようにした。

### 変更点

- `make_feedback.py` と `make_change_report.py` は、既定で `~/.agents/feedback/japanese-readability-editor/` に JSON を保存する。`--out-dir` で保存先を変更できる。
- 記録ごとに別のファイル名を付け、既存ファイルを上書きしない。保存先は標準エラーの `saved_to` に表示し、従来の JSON 標準出力も維持する。`> feedback.json` などのリダイレクトは不要になる。
- 保存に失敗した場合は終了コード 2 とし、JSON を標準出力に出さない。書き込みに失敗した未完成ファイルは削除する。
- POSIX 環境では新規ファイルを `0600` で作成する。Windows のアクセス権は保存先から継承する。自動保存自体は暗号化ではない。
- 通常の文章推敲では記録用スクリプトを自動実行しない。送信も自動では行わない。問題の報告票には原文と結果が含まれる。

### 検証

- 保存内容と標準出力の一致、連続実行での既存記録の保持、既定の保存先、日本語・絵文字を含む保存先、POSIX のファイル権限、保存失敗時の終了コードと未完成ファイルの削除を検査した。
- ホストごとの実際のスキル呼び出しと、文章推敲の品質変化は、この変更の検証対象に含めていない。
