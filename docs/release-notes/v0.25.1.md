# v0.25.1

既存の意味保持の規則を具体的な照合手順で補った。新しいモードや判定機能は追加しないため、パッチ版とした（#214）。

## 変更

- 保証・約束の主体、対象、条件、例外、範囲、強さを照合する。監視や検査の方針を、再発しない保証に変えない。
- 入れ子文では、述語ごとに主体と相手を照合する。自然な主題は不要に変えない。
- 意味を保つ例と誤った改稿の自作例を追加した。
- yomiyasu、humanizer、textlint の確認記録と、解析した範囲の基準を更新した。上流の文章・実装は転載していない。

## 検証と限界

自作12組の意味同一性を同じ条件で各2回判定し、新旧ともすべて正解だった。この評価では改善差や悪化は観測していない。実際の推敲品質と実利用の効果は未確認。

比較スクリプトの自動判定は変わらない。A/B の手動照合を補う変更であり、C/D の出力契約は変えていない。

既存テストは963件実行（13件スキップ）、失敗0件。計画、実装と評価結果は Claude Code でレビューし、指摘を修正した。
