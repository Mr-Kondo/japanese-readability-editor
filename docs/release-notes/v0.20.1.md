## v0.20.1

通常の文章推敲(モード B)でも、本文を含まない変化の記録を自動保存するようにした。

### 修正

- v0.20.0 は、記録用スクリプトを明示的に実行したときだけ保存していた。通常の推敲では実行しない指示が残っており、Windows の Codex で文章推敲を依頼してもファイルが作られなかった。
- モード B では最終結果が確定した後に `make_change_report.py` を実行し、保存を確認してから原文と結果の一時ファイルを削除する。変更不要で原文をそのまま返す場合と、「完成した文章だけ」を求められた場合も含む。
- 保存先は従来どおり `~/.agents/feedback/japanese-readability-editor/`。Windows では `%USERPROFILE%\.agents\feedback\japanese-readability-editor\`。保存できなければ未保存と伝える。
- 原文・結果を含む問題報告票は、利用者が報告を依頼したときだけ作成する。自動送信はしない。モード A/C/D の自動記録は追加していない。

### 検証と限界

- 手元の Codex に人工の文章の通常推敲を依頼し、ツール実行と保存済み JSON を直接確認した。詳細は [検証記録](https://github.com/Mr-Kondo/japanese-readability-editor/blob/main/docs/validation/normal-rewrite-feedback-2026-10-23.md)。
- 利用者の Windows 端末での実呼び出しと、インストール済みスキルの更新は未実施。
