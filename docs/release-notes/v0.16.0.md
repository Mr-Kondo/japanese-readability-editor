## v0.16.0

Skill を読み込んだときの入力トークンを減らす変更です。規則・数値・コードは変えていません。

### 変更点

- `SKILL.md` の本文を、204行(約7,700トークン)から168行(約6,570トークン)に縮めました。全モードでは使わない手順を、`references/` に出しました。
  - `references/scripts.md`: スクリプトの一覧(用途、コマンド、出力、終了コード)、照合(`compare_rewrite.py`)と計測(`measure.py`)の手順。
  - `references/kokugo-check.md`: 国語の表記・用法の適用手順。
- スクリプトの扱いを、本文に明記しました。「実行して出力だけを使う。ソースは読まない」。
- 100行を超える参照ファイルに、目次を付けました。
- Gemini Apps 向けの貼付用指示には、国語の適用手順を Part 4 として埋め込みます。
- 計測の道具 `tools/measure_skill_tokens.py` を足しました。リリースのノートは、`docs/release-notes/v<版>.md` があれば、それを使います。

### 計測した効果(Sonnet 5.5、各5回。詳細は [計測の記録](../validation/skill-token-usage-2026-10-19.md))

- 本文は -15%(7,698 → 6,567 トークン)。公式の目安の5kトークンには届いていません。
- 書き換え(B)の1回あたりの入力側は、版ごとにまとめて流した最初の計測では、3入力15回の中央値が 160,247 → 123,404 でしたが、**版を交互に実行した各45回の追加計測では、平均の差が -2.1%(標準誤差の0.35倍)で、検出できませんでした。最初の差は取り下げます。** 本文の縮小による節約は、見積もりで約2%です。
- Paragraph-only(C)の遵守(改行の挿入だけ)は、10/10 のままです。

### 減らなかったこと・分かったこと

- 実行ごとのばらつき(ターン数が5〜12)が大きく、5回ずつでは5%程度の差は読めません。
- C の手順を参照ファイルにすると、読み込みのターンが増えて、長文で +47% になったため、本文に残しました。
- スクリプトの表を本文に置くと、`compare_rewrite.py` の実行が 4/15 から 13/15 に増え、トークンが増えたため、表は外しました。1回の実行は、約4〜6万トークンです。
- スクリプトのソースを読んだ回は、前も後も 0/142 でした。国語の検査(`check_kokugo.py`)は、前の版でも一度も実行されませんでした。
- 短い文章でスクリプトを省く目安は、書いていません。スクリプトのコストは長さに依存せず(1ターン分)、測った範囲に境目がありません。省いたときの見落としの増え方は、未測定です。
