## v0.17.0

Skill の版を確認でき、実行環境を記録できるようにした。通常の依頼のトークンは増えない。

### 変更点

- Skill に `VERSION` を足した。リリースのタグと一致しない Release は、作らない(`release.yml` で照合する)。
- `scripts/skill_info.py` を足した。
  - `python3 scripts/skill_info.py --version` で「スキル名 版」の1行を出す。
  - 引数なしで、版・OS・アプリ(名前と版)・モデル・日付を JSON で出す。何も書かない。
  - 標準エラーに、保存先の `~/.agents/skill-env/<スキル名>.json`(`save_to`)を出す。スクリプトは書き込まない(Skill のスクリプトは読み取り専用という保証を保つ)。JSON を保存するのは、実行したエージェントで、保存はその操作として利用者に見える。
  - ユーザー名・ホスト名・パス・メールアドレスは出さない。
- 実行するのは、版や環境を尋ねられたときと、問題の報告票を作るときだけにした(本文に1文)。実行すると、Bash のターンが1回増え、1回あたり約4.6万トークンの入力が増えるため、通常の依頼では実行しない。
- 報告票の手順に、`skill_info.py` で版とモデルを取って `--skill-version` と `--model` に渡す説明を足した。

### 確認したこと・していないこと

- アプリの推定は、Claude Code の `AI_AGENT`(名前と版)だけ、実環境で確かめた。Codex、Gemini CLI、OpenCode は環境変数の目印による推定で、実環境では未確認。違えば `--app` と `--app-version` で指定する。
- モデル名は、環境から分からない。実行する側(エージェント)が `--model` で渡す。渡さなければ `unknown` になる。
