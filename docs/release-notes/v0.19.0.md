## v0.19.0

Skill を使った後の変化を、本文を含まない選択式の記録(JSON)として残せるようにした。

### 変更点

- `scripts/make_change_report.py` を追加: 書き換える前の文章と返した文章から、9つの検査(数値・URL・コード・用語・原文にない文・脱落・否定・推量などの表現・文体)ごとの状態、方法、向きと、読みやすさの方向(文字数・長い段落・長い文・短い文の連続が減ったか、同じか、増えたか)を出す。原文・結果・引用・行番号・ファイル名・パス・件数は出さない。読み取り専用で、書き込みも送信もしない。
- 方式は [official-prompt-tailor](https://github.com/Mr-Kondo/official-prompt-tailor) の `private_feedback.py` を参考にした(固定の検査項目、状態と方法の組、ランダムな `case_id`、総合点や改善率を出さない)。人が見比べたもの(`human`)と、モデル自身の申告(`model_self_report`)を区別し、候補が挙がっていない検査には結果を付けられない。
- `references/change-report.md` を追加: 利用者が求めたときだけ読む。通常の依頼では実行しない(`SKILL.md` に足したのは参照1行のみ)。
- `docs/feedback.md` に手順と見方、`docs/change-report-example.json` に人工例を追加。

### 未確認

- `skill_info.py` の環境の記録とは別。こちらはアプリ名・版を記録しない。
