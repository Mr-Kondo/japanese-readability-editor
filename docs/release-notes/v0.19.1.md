## v0.19.1

B で `compare_rewrite.py` を必ず実行させる手順(v0.18.0)を、本文だけを返す依頼でも省かないことを明記した。

### 変更点

- `SKILL.md` の「出力」の節に、「本文だけを返す依頼でも、モード B の返す前の照合(スクリプトを実行できる環境では `compare_rewrite.py`)は省かない。照合の結果は表示しない」と書いた。「完成した文章だけを返す」「内部の確認手順は表示しない」の記述が、照合を省く理由になるという仮説に基づく。実際に省いた理由は未確認。
- 道具(`tools/evaluate_readability.py`)を直した。記録の `flags` に実際の値を入れ、出力ごとに `num_turns` と費用を記録する。`--model` で生成のモデルを選べる。
- Claude Code の `SessionStart` フックで、モデルを介さずに実行環境を記録する手順を、`docs/scripts.md` に書いた(任意。既定では有効にならない)。
