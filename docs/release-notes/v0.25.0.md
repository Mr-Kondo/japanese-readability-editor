## v0.25.0

読み手に暗算をさせない規則を足した。差分・比率・合計は、原文の数値から計算して示す(#204)。

### 変更

- `references/readability-rules.md` に節「差分・合計の計算」を足した。計算に使う数値は原文にあるものだけにし、原文にない数値・日付・期限は作らない。数が足りないときや、「約」「超えた」のような概数のときは、計算しない。すでに計算した値があれば、足さない。
- `SKILL.md` に、同じ趣旨を足した。行数の上限(175行)のため、既存の「原文にない数値、事例、留保、断定を足さない」の項と1行にまとめた。評価に使った文面は、独立した1行だった。まとめた後の文面は、評価していない。rules の節にある「すでに計算した値があれば、足さない」は、SKILL.md の1行には入れていない。

### 効果の確認

- 旧版(0.24.1)と新版を、同じ条件で比べた(自作20本×3回、モデル `claude-sonnet-5-5`)。記録は `evals/cognitive-load-a2-result.md`。
- 新規8本で、差・合計を示した出力は、旧版0/24、新版6/24。回帰4本は、旧版0/12、新版10/12。計算は人が全件確認し、すべて正しかった。control(概数・数が足りない例など)は、旧版・新版とも作り足し・混入・欠落が0件。
- 最初の文面(条件を前に置く)は、効果が出なかった(新規 0/24)ため採用せず、言い切りの文面にした(`evals/cognitive-load-a-result.md`)。

### 影響を受ける使い方

- 数値が散らばる文章の推敲で、差・合計が足されることがある。原文にない数値は足されない。

### 確認していないこと

- 新規8本のうち、5本は新版でも計算が足されなかった(効く型と効かない型がある)。
- 自作の短い文での結果で、実利用の効果の証明ではない。
- 作り足しと判定された1件(増加率25%)は、人が読んで正しい計算と確かめた。判定の許可値に増加率を入れていなかったためである。計画の基準の字面では不採用だったが、この扱いを、利用者の許可を得て採用とした。
