## v0.21.3

yomiyasu v2.5.0 を参考に、読点と利用者が指定した文書構造の保持を補強した。

### 修正

- 推敲で追加する読点にも構造上の理由を求め、短い主語・目的語・副詞を一律に区切らない。随筆などの意図された間は保つ。
- 指定された見出しの形と、残すよう指定されたまとめの節を保つ。文面固定の指定がなければ、まとめ本文は推敲できる。
- 返却前の照合に、指定構造と追加した読点の確認を含めた。

検証方法と限界は [上流の確認記録](../upstream/reviews/yomiyasu-2.5.0-partial.md) に記載する。これは変更内容の記録であり、GitHub Release の公開を示さない。
