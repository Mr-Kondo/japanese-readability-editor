# Skill 読み込み時の入力トークンの計測(2026-10-19)

SKILL.md を軽くし、スクリプトの扱いを明記したときに、入力トークンが減るかを、実行で測った記録です。[Issue 83](https://github.com/Mr-Kondo/japanese-readability-editor/issues/83) の作業です。効果は予測ではなく、この記録の範囲で測った値です。標本が小さいので、検定はしていません。

## 結論

- **SKILL.md の本文**は、約7,700トークンから約6,570トークンに減りました(-15%)。公式の目安の5kトークンには届いていません。残りの本文は、A と B の両方で使う規則で、読み込みを分ける対象ではないためです。
- **B(Rewrite)の1回あたりの入力側**は、3入力を合わせた15回で、中央値が 160,247 から 123,404 に、平均が 155,203 から 133,186 に減りました(-23%、-14%)。ただし、1回の実行の差(ターン数が5から12まで)が大きく、本文の縮小で説明できるのは、1回あたり約8千トークン(約5%)と見積もっています(1,131トークン × 約7ターン。実測ではなく、見積もりです)。残りの差は、実行ごとのばらつきの可能性が高いです。
- **C(Paragraph-only)の手順を参照ファイルに出すと、損でした。** C のたびに読み込みのターンが1回増え、長文の中央値が 182,975 から 269,310 に増えました(試作1)。本文に戻した版では、増えていません。
- **スクリプトを実行する回数が、トークンを最も動かしました。** スクリプトの表を本文に置くと、`compare_rewrite.py` を実行した回が 4/15 から 13/15 に増え、トークンが増えました(試作2)。表を外し、元の照合の文に戻すと、5/15 に戻りました(最終)。
- 使い分けの目安に**数字は書いていません。** 理由は「スクリプトを省く目安」の節に書きます。

## 条件

- 計測の道具: [tools/measure_skill_tokens.py](../../tools/measure_skill_tokens.py)。Skill を、隔離した一時プロジェクトの `.claude/skills/` に入れ、`claude -p`(Claude Code 2.1.292、`--setting-sources project`)で実行します。ユーザーの設定とプラグインは外しています。usage は、実行結果の合計です。
- 依頼: 「japanese-readability-editor スキルを使って、doc.md をモード B(または C)で読みやすく直してください。doc.md を直接書き換えてください。」Skill の指定は、発火の差を除くために入れています。
- 入力([evals/token-usage/inputs/](../../evals/token-usage/inputs/)): 短い(約450字、docs/usage.md の一部)、中程度(約2,900字、docs/usage.md 全体)、長い(約9,200字、docs/user-guide.md 全体)。本リポジトリの文書です。
- モデル: Sonnet 5.5(`sonnet`)。同じ入力・同じ条件で5回。Opus 5.5 は、中程度の入力だけ3回です。

## スクリプトを省く目安

**数字は書いていません。** 理由は次のとおりです。

- スクリプトのコストは、文章の長さに依存せず、1ターン分(約4.6万トークン)です。出力は短く(中央値 332字)、文章が長くなっても、スクリプトを実行しない方が安くなる境目は、測った3つの長さ(約450字、約2,900字、約9,200字)の中に現れません。
- スクリプトの利点は、トークンではなく、意味の変化の見落としを減らすことです。この計測は、利点を測っていません。短い文章でスクリプトを省いたときの、見落としの増え方は、未測定です。
- 数字を書くには、この利点を測る評価が要ります。省く目安は、規則の追加にあたるので、旧版と新版を同じ評価で比べてから決めます(別の Issue)。

## 未確認のこと

- Opus 5.5 の最終版、Haiku 5.5、他のエージェント(Codex、Gemini CLI など)の挙動。
- 長文の出力量は、約9,200字までです。数万字の文書は測っていません。
- 実行ごとのばらつきが大きい(ターン数が5〜12)ため、5回ずつでは、5%程度の差は読めません。
- 1つのバッチの中で、キャッシュの状態が実行順に影響する可能性があります(1時間のキャッシュを使用)。

## 再現

```bash
python3 tools/measure_skill_tokens.py run --skill-dir skills/japanese-readability-editor --label after \
  --input medium=evals/token-usage/inputs/medium.md --repeats 5 --out "$TMPDIR/runs"
python3 tools/measure_skill_tokens.py summary --out "$TMPDIR/runs"
```

`--variant mode-c`(C の実行と改行のみの判定)、`--variant no-scripts`(スクリプトを省く指示)、`--model opus` があります。`claude -p` は費用がかかります。1回あたり約0.12〜0.2 USD(Sonnet 5.5)でした。認証の期限が切れていると、サンドボックスの中では更新できず、全回が失敗します。
