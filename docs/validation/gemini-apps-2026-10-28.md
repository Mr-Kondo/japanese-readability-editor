# Gemini Appsの取り込み・参照・Chat動作（2026-10-28）

## 1. 文脈

[Issue #87](https://github.com/Mr-Kondo/japanese-readability-editor/issues/87)で未確認だったGemini Appsを、利用者本人のログイン後に確認した。
対象はweb版のSkills管理とGemini FlashのChat。Skill本文はv0.21.2で、過去の計測に用いたものと同じ。通常の利用者設定や他のSkillは変更していない。
公開済みの人工入力だけを使い、生の画面・応答・ZIPはGit除外の`feedback/issue-87-20261028/`に保持する。

## 2. 核心的な論理

**証拠:** 元の32ファイル入りZIPは「サポートされていない形式」のファイルがあるとして拒否された。そこから拡張子のない`VERSION`だけを除いた31ファイル入りZIPでは、アップロード、メタデータ読み込み、保存が完了した。
ファイルツリーでreferences・scripts・dataを確認し、Skill一覧の有効欄への登録も確認した。

**推論と限界:** この組み合わせではVERSIONが取り込み拒否の原因だったと切り分けられる。すべての拡張子なしファイルや、将来のクライアントの挙動へ一般化しない。
受け入れられた形式であることと、Chatでコードを実行できることは別である。

## 3. 重要ポイント

| 構成・操作 | 観測結果 | 言えないこと |
|---|---|---|
| 元の32ファイル入りZIP | 未対応形式として拒否 | 拒否メッセージ単独では原因ファイルを特定できない |
| VERSIONだけを除いた31ファイル | 保存成功、参照・コード・データのフォルダーを表示 | コード実行の成功 |
| コード同梱版をChatで呼び出す | モデルがコード同梱によるロード不可を報告。ハッシュ・終了コード・実行結果なし | 製品全体やTaskでの実行可否 |
| scripts/data/VERSIONを除いた通常構成16ファイル | 取り込み・保存、参照内容との一致、モードB本文出力を確認 | スクリプトによる照合・記録の実行 |

通常構成の置き換え後に管理画面が空白になった。再読み込み後、Skillは無効欄にあり、ファイルツリーはSKILL.md・assets・referencesとなっていた。有効化して以後の確認を実施した。空白画面の原因は特定していない。

## 4. 具体例

コード同梱版には、参照ファイルのSHA-256計算、同一の人工文2ファイルの保存、compare_rewrite.pyとmeasure.pyの実行を依頼した。
Gemini Flashは、Chatではコードを含むSkillをロードできず実行環境もないと回答し、仮の値を作らなかった。これはモデルの応答として記録する。独立した実行ログや終了コードは得られていない。

通常構成では、references/scripts.mdの先頭見出し、順序どおりの第2階層見出し3件、通信の有無と記録を新規保存するスクリプト2件の記述を質問した。回答は元ファイルと一致した。
参照利用の根拠になるが、Pythonによるハッシュ計算の証拠にはしない。

続いて、承認・保存期間30日から60日・監査対象の例外・報告を含む人工文をモードBで1回推敲した。本文の出力を確認した。
数値、承認条件、例外、変更前の確認、未承認・対象不明時の維持、担当者と報告先は対応していた。一方、常体から敬体へ変わった。総合的な指示適合や意味保持の合格判定はしていない。照合・変化記録のスクリプト実行証拠もない。

## 5. 平易な説明

わかりやすく言うと、VERSIONを外せば取り込めたが、Chatではコードを除いた構成で参照を使うところまでを確認したということである。

## 6. 自己批判的考察

取り込み結果と参照の一致に対する自己評価の信頼度は0.98。一般的な意味保持能力や全Gemini Apps環境での対応を示す値ではない。
同じアカウント・Gemini FlashのChatでの少数確認であり、Task、他モデル、ブラウザー以外のクライアントは未検証。
モデルが述べた制約と、UIで直接確認した保存・一覧表示を区別した。

## 7. 修正・検証・保管

Gemini Apps用エクスポーターだけでVERSIONを除外するよう修正し、拒否されるファイルを生成しない回帰テストを追加した。通常のZIPと他環境向けのコピーにはVERSIONを残す。
scripts/dataを除く構成とSkill本文・版0.21.2は維持する。配布文生成テスト37件、`uv run --locked python tools/check_all.py`、`git diff --check`が成功した。

検証のため追加したアカウント上のSkillは終了後に無効化し、無効欄への表示を確認した。元のZIP、VERSIONだけを除いたZIP、通常構成のZIP、応答とスクリーンショットを非公開で保持する。
Hermesの最終応答、Gemini CLIのモデル接続、作業用worktreeの削除保留は[前回の記録](issue-87-agents-2026-10-28.md)とIssueを維持する。
