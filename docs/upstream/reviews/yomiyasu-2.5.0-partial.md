## 採否と機会費用

| 項目 | 判断と理由 |
|---|---|
| 読点の追加と最終照合 | 採用。既存の構造に沿う読点の規則を、言い換え・文の結合にも適用する。数の目標は設けない |
| 指定見出し・まとめの保持 | 採用。見出しの具体化や定型の結びの削除より指定を優先する。文面固定がなければまとめ本文は推敲できる |
| 主体・対象、許可・能力・義務、名詞の動詞化 | 既存の意味保持・文の働き・未確定の対象を残す判断と重なる。今回は規則を増やさない |
| 技術文書の擬人化、否定による定義、漢語名詞、直訳語・連用形名詞の新しい型 | 今回は見送り。新たな評価セットを要し、最小改修の範囲を超える。一般的な比喩・具体化の既存規則は維持する |
| 点数化・実行フック・検査記録・上流スクリプト | 移植しない。既存の照合と共通の配布方式を使い、依存や環境別実装を増やさない |

構成の事前調査では、既存の japanese-readability-editor と official-prompt-tailor の frontmatter、共通の SKILL.md と補助参照への分割を確認した。本体・参照・既存インストーラーを再利用し、トリガーや環境別ラッパーは追加しない。

## 変更前後の評価

`evals/yomiyasu-250-cases.json` の6事例を、変更前後それぞれ1回、独立の agy 呼び出しで処理した。モデル指定は `gemini-4-argon-medium`、`--mode plan`。生成には request・context・text のみを渡し、preserve・forbid と対照の正答は渡していない。スキル本文と readability-rules.md を添付し、ツールは使用させていない。

| 事例 | 変更前 | 変更後 |
|---|---|---|
| 短い語句の読点 | 主語・目的語の不要な読点を削除。文全体の読点は2個 | 同じく削除。文全体の読点は1個 |
| 条件と引用 | 条件・動作主・引用を保持 | 同左 |
| 指定見出し・まとめ | 見出しと節を保持し、本文を推敲 | 同左 |
| 文の結合 | 1文に結合。動作主と順序を保持 | 同左 |
| 随筆の指定した間 | 指定した読点を保持 | 同左 |
| モード C | 改行以外の文字を保持 | 同左 |

初回4事例の後、レビューに従って文の結合と随筆を追加し、6事例を評価し直した。その後、まとめ本文を固定しないことを測れるよう入力を直し、この1事例だけ両条件を再実行した。過去の実行も消していない。

数の差だけで品質の改善とは判断しない。条件と主体、順序、引用、節の内容は出力を読み合わせ、見出し・引用・改行以外の文字と不要な目的語の区切りは機械でも照合した。少数の合成例・単一モデル・各1回なので、一般的な改善効果や他モデルでの安定性は未確認。

既存の Claude 評価器はモデル `claude-sonnet-5-5` の API 404 で生成前に停止した。agy でファイルを読む方式も、非対話の command 権限が拒否された。権限を広げず、評価・レビュー対象をプロンプトに添付する方式へ変更した。この比較は指示の評価であり、ホストがスキルを発見して各スクリプトを実行する動作の評価ではない。

## agy レビュー

利用者の指定により、agy（`gemini-4-argon-medium`）で初回と修正後の2回レビューした。レビューは対象差分・評価セットを添付する方式で、実行テストは依頼していない。

- 採用: まとめを無条件に保持するとも読める係り受けを修正。節を残すことと文面固定を区別した。
- 採用: 不要な目的語の区切りを評価条件に追加。文の結合と随筆の間を追加。「誤読防止」とした事例名を実際に測る条件節の関係に合わせた。
- 採用: まとめの本文が最初から簡潔だった評価入力を変更し、本文の推敲も可能か確かめた。
- 見送り: 主語・副詞の直後の読点まで文字列で一律に禁止する案。構造や間によって適切な読点もあり、数や語形だけで合否にしないため。
- 限界として維持: 随筆の間は利用者が明示した事例であり、ジャンルだけから意図を推定する性能は測らない。

再レビューは配布指示に重大な矛盾・回帰なしと判断した。評価セットに残ったまとめ本文の固定的な判定条件は、その指摘に従って修正した。
