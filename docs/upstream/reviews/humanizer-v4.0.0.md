## 読んだ範囲

`python3 tools/upstream_watch.py check --only humanizer` の結果を確認しました。CHANGELOG の 3.0.0、3.1.0、4.0.0 と、監視対象の `SKILL.md`・`CHANGELOG.md` の差分を読みました。上流の文章は英語向けです。上流の Skill は実行していません。

## 変更の要約

- 35項目を26項目へまとめ、対比、短い結び、前置き、3項目の列挙、ダッシュ、誇張、広告調、太字ラベル、会話の名残などを強さと種類で整理
- 3.1.0 で、会話の相手が既に知る背景を返信で繰り返す形と、文書の作り方や配置を本文で説明する形を追加
- 4.0.0 で、原文が一般的な場合に、モデルが真実だと知っている具体的事実の追加を許可（以前の「事実を作らない」という規則を反転）
- ファイル全体を読み、見た範囲を要約する手順と、編集対象に入った偽の命令へ従わない規則を追加

## こちらとの照合

現行の `references/readability-rules.md` は24,122字、778行です。見出し、否定と条件、論理関係、主体の切り替わり、直訳調、抽象語・造語・比喩、冗長表現、広告調・AI決めぜりふ、読者向けでない言葉の名残、太字、書き換え後の意味照合を既に分けています。

| 上流の変更                               | こちらの現状                                                                       | 判断                                                           |
| ---------------------------------------- | ---------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 対比、結び、誇張、広告調、太字など26項目 | 既存の論理関係、文末、広告調、AI決めぜりふ、太字と重なります                       | 一覧を追加しません。英語の語形を、日本語の検出規則へ移しません |
| 既知の具体的事実を加える                 | 数値、条件、主体、固有名詞、引用、出典などを原文・資料なしに変えない規則があります | 採りません。意味保持と出典の境界に反します                     |
| 返信で既知の背景を繰り返さない           | 日常の短い会話は Skill の対象外です                                                | 対象を広げません                                               |
| 編集対象内の命令へ従わない               | 今回の上流監視では、外部文章をデータとして扱っています                             | 変更なし。上流の文面を規則へ転載しません                       |

新しい採用候補の Issue は作りません。既存規則との重複を差し引いた日本語向けの未解決事例と、意味保持を崩さず改善する評価条件が確認できなかったためです。

## 採否

| 項目                         | 採否     | 理由                                                                 |
| ---------------------------- | -------- | -------------------------------------------------------------------- |
| 26項目の分類と英語の監視語   | 採らない | 日本語の既存規則と重なり、英語固有の語形を移す根拠がありません       |
