## こちらとの照合

| 上流の変更                          | こちらの範囲                                             | 判断       |
| ----------------------------------- | -------------------------------------------------------- | ---------- |
| 翻訳、投稿、短編集、出版形式の管理  | 翻訳と出版を扱いません                                   | 採りません |
| 人物の年齢、時系列、独自検査        | 設定管理を行わず、任意設定の文字列を単純一致で確認します | 採りません |
| 画像・脚注・EPUB・DOCX・HTML の生成 | 原稿を生成形式へ変換しません                             | 採りません |
| プロジェクトの収集・書き換え・履歴  | 配布スクリプトは入力を変更しません                       | 採りません |

新しい採用候補の Issue は作りません。追加機能は、2026-10-10 の設計で採らないと決めた設定管理・翻訳・出版・ファイル書き換えの範囲にあります。
