## 何が変わったか
変更は、同梱の `story` CLI の機能追加にひもづく説明が中心である。

- 変更を実際に行う前に、コピー上で試して影響だけを見る `story impact`（人物の死、章・場面の移動）
- 返却された DOCX のコメント・変更履歴を一覧にする `story notes`
- 締切・連載日を ICS にする書き出し
- 場面間の移動距離と移動手段の整合を見る `travel-too-far` と、地図の座標・距離の書き方

## こちらとの照合
いずれも CLI と設定ファイルの構造を前提とする。当スキルは配布スクリプトを読み取り専用にし、小説の設定管理や出版を扱わない（2026-10-14 の判断どおり）。考え方で拾えるのは次の 2 点だけである。

| 項目 | 判断 |
|---|---|
| 変更の前に影響を試す | 採らない。本文の書き換えは `compare_rewrite.py` で後から前後比較する構成で、重なる |
| DOCX のコメントの作成者名は承認ではない | 採らない。当スキルは DOCX の変更履歴を扱わない |
| CLI・ICS・距離検査・地図 | 採らない（取り込まないと決めた範囲） |

採用候補の Issue はなし。
