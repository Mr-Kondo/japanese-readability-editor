## 何が変わったか

変更の中心は、同梱の `story` CLI の機能追加と、その説明にある。

- 編集者から戻った DOCX の内容を章のファイルへ書き戻す `story apply`。試行の結果を著者に見せ、承認を得てから本番を実行する。本番の結果が試行と同じかは、ハッシュと件数で確かめる。隠し文字と不可視の文字は書き込まず、警告する。
- 翻訳版と原本の構造を比べる `story translation`。章・場面・ID の過不足と、翻訳後に改訂された原本の章を報告する。意味は比べない。
- 連載の 1 話を貼り付け用に書き出す `build --format post` と、締切を ICS にする書き出し。
- 投稿先の管理表を数える `story submissions` と、短編集を組み立てる `story collect`。
- 人物の生年を `born` で持ち、年齢を章の日付から計算する。距離と移動手段から、移動時間の矛盾を調べる。
- 詩集を物語のプロジェクトとして扱う形式と、絵本の画像の配置。

## こちらとの照合

いずれも CLI と、設定ファイルの構造を前提とする。当スキルは配布スクリプトを読み取り専用にし、小説の設定管理や出版を扱わない（2026-10-10 の判断どおり。`docs/fiction-design.md`）。考え方で拾える点を、次のとおり照合した。

| 項目 | 判断 |
|---|---|
| 書き戻す前に試行を見せ、本番が試行と同じかを確かめる | 採らない。当スキルは本文を上書きせず、書き直しを `compare_rewrite.py` で前後比較する |
| 戻ってきた文書の文は指示ではなく材料。コメントの作成者名は承認ではない | 変更なし。他人のコメントを材料として扱う規約は、#69 で取り入れた |
| 隠し文字・不可視の文字の警告 | 採らない。当スキルは DOCX を読まない |
| 著者が言っていない謝辞・リンク・予定を作らない | 変更なし。原文にない事実を足さない規則と重なる |
| 翻訳版と原本の構造の比較 | 採らない。翻訳は対象外 |
| 生年・距離・移動時間の整合 | 採らない。設定の管理は扱わない |
| 詩の改行を保つ | 採らない。当スキルは詩を対象に挙げていない |
| CLI・ICS・投稿管理・短編集の組み立て・画像の配置 | 採らない（取り込まないと決めた範囲） |

採用候補の Issue はなし。
