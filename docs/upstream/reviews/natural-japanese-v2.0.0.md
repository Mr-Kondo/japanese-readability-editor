## 何が変わったか

- `critical-thinking`（新しいスキル、5 ファイル）: 稟議書や提案書の論旨を検査して直す。文書の中で筋が通っているかの検査と、文書の外から前提を問う検査に分かれる。論理構造を YAML に書き出し、指摘は行番号つきの問いの形で返す。直すときは、書き手にしか答えられない問いを 3 つまで聞き、確認事項を別のファイルに出す。`coverage.py` は、YAML が文書の全行を拾っているかを調べる。
- `natural-japanese/SKILL.md`: 論旨の検査は新しいスキルへ渡す、という案内を足した。段落ごとの確認を、利用者への報告や返答の文にも当てる。
- `lint.py`: 和語の動詞を名詞にした語（4 語の表）が、助詞の前に置かれている箇所を示す `wago_nominalization`。漢語のほうがふつうの語に限る。
