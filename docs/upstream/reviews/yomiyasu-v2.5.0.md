SKILL.md の差分（全体）、`references/` の差分の見出しと新規ファイル（calques、script、review-points、lists）、`scripts/` の差分は規則名と追加行の抜き出しまで。上流のスクリプトは実行していない（データとして読んだ）。lint（差分約 2,900 行）、diff（同約 2,400 行）の本体は、全体を読み切っていない。代わりに、既存の規則が変わったかを、削除行で確かめた。5 本のスクリプトの削除は計 479 行（lint 114、diff 211、check 120、hook 31、markdown_visibility 3）で、追加の約 5,000 行より少ない。数値の閾値や重大度に当たる削除行は、抜き出した範囲では見つからなかった（正規表現と範囲の調整が中心）。references の削除は 59 行で、語の一覧の説明コメントが多い。変更は追加が中心、という判断の根拠はこれである。

## こちらとの照合（実測を含む）
- 意味の保持の語（実測）: `compare_rewrite.py` に、「してよい → できる」「未定 → 来月」「キャッシュの削除で → 削除した結果、」＋原文にない約束文、の組を与えた。出たのは `ability: 0 -> 1` と約束文の `unmatched sentences` 1 件だけだった。許可の語と状態の語は型がなく、因果の接続も示さない。→ #141。
- 書き換えで足された担当・役割の語: 先行の記録のとおり（#136）。
- 括弧内の文: natural-japanese 側の候補（#137）。yomiyasu の変更の要約（CHANGELOG と SKILL.md）には、括弧内の文の検出は出てこない。
- 読点、見出しの形、まとめの保持: #132 で採用済みの範囲。残りは #57 の C・E・F の評価候補。
- 直訳語の型 4（英語の短い術語への漢字 1 字）、連用形名詞、定型句の info 規則: 専用の検出器は当面見送り、#57 の C・F で評価してから決める。
- 構造の読み違い（目的語のない他動詞、主題の「は」の掛かり、漢語の名詞だけの文）: 上流は規則文の追加が中心。こちらの `readability-rules.md` との重なりは、規則文を比べていない。#57 の F の評価候補。
- 文書の種類 script: #57 の A に含まれる。

## 外部の意見

## 限界
- lint と diff のスクリプト本体は、規則名と追加行までの確認で、実装の全体は読んでいない。上流のスクリプトは実行していない。
- 上流の改善率は、こちらの改善の証拠にしない。
- 保証の強さ、調査中の状態、引用の書き方の変化は、`compare_rewrite.py` で実測していない（#141 の評価で測る）。
- 語の一覧は網羅できない。#141 の評価で誤検出を測る。
