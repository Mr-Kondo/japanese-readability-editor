## 現状の実測

現行の `compare_rewrite.py` を regex 解析で人工7組に実行した。終了コードはすべて0。

| 前 → 後                                           | 結果                       |
| ------------------------------------------------- | -------------------------- |
| 午後3時 → 午前3時                                 | 候補なし                   |
| ▲3.2% → 3.2%                                      | 候補なし                   |
| 初日は田中さん、二日目は鈴木さん → 入れ替え       | 候補なし                   |
| 大阪会場は田中さん、東京会場は鈴木さん → 入れ替え | 候補なし                   |
| 会議は午後3時、懇親会は午後6時 → 18時と15時       | 数値の差（3時、6時、18時） |
| 旧プランの利用者は → 新プランの利用者は           | 候補なし                   |
| 090-1234-5678 → 090-\*\*\*\*-5678                 | 消えた数値 1234            |

「旧プラン→新プラン」の保証の相手の変更は、候補が出なかった。保証の手動照合の規則（#214）の範囲であり、今回は新しい候補にしない。

## 外部の意見と限界

この確認では、外部レビューを受けていない。採用候補は評価の計画を作る段階で、外部の意見を取り入れる。
