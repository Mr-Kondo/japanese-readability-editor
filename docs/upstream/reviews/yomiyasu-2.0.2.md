# yomiyasu v2.0.2 の確認

- 参考先: [nanaism/yomiyasu](https://github.com/nanaism/yomiyasu)（MIT）
- 確認した基準: コミット `5b7cacc`（v2.0.2 のリリース）。その後の先頭 `79d15a6` は README の変更だけで、監視パスに変更はない。
- 確認日: 2026-10-19
- 範囲: v2.0.1（`84e1f5b`）から v2.0.2 まで。追跡 Issue は #76。

## 何が変わったか（要約）

| 項目 | 内容 |
|---|---|
| 規則 | 変更なし。SKILL.md の本文と references は同じで、出力も同じと上流は述べている |
| 呼び出し | description を、名前を出して頼んだときだけ使う形に変えた |
| 速度 | 崩れた太字が多い長い段落の検査（lint、diff）を高速化した |
| 状態フォルダ | `~` で始まる指定を、ホームフォルダに置き換えるようにした |
| 配布 | プラグイン設定の重複を整理。英語の短い紹介、CI を追加 |

## こちらとの照合（実測を含む）

- 太字の検査の速度: こちらの `find_unrendered_bold`（`measure.py`）に、`これは **「重要」**です。` を 1 段落に 1,000／2,000／4,000／8,000 組並べて与えた。0.002／0.005／0.013／0.04 秒で、上流の 2.0.1 のような 2 乗の増え方はない。
- 状態フォルダ: こちらの配布スクリプトは状態を保存しない（読み取り専用）。該当しない。
- 呼び出しの限定: こちらは、日本語を書く・直す依頼で自動的に使われることを価値とする。名前を出した依頼だけに限ると、その価値が失われる。
- 英語の紹介、CI、プラグイン設定: こちらの配布構成とは別の課題で、今は必要がない。

## 採否

| 項目 | 採否 | 理由 |
|---|---|---|
| 名前を出したときだけ使う description | 採らない | 自動の呼び出しが目的。上流は、毎回使いたいときに指示ファイルへ 1 行足す運用にしている。こちらは逆 |
| 太字検査の高速化 | 採らない | 実測で問題がない |
| 状態フォルダの `~` 展開 | 採らない | 状態を持たない |
| そのほか | 採らない | 規則の変更がない |

## 限界

- 上流の測定（2.0.1 と 2.0.2 の呼び出し率）は、上流の文章を読んだ範囲で、こちらでは再現していない。採らない判断には使っていない。
- 追加の採用候補の Issue はない。
