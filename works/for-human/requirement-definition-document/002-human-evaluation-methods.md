# 人手評価と改善の方法

## 要点

- 意味の保持と可読性は別に評価する。読み手の理解度は、別の課題として試す。
- 比較評価は改定の前後に便利だが、理由と絶対的な品質は示さない。好みに欠陥の種類、位置、修正案を組み合わせる。
- 最初の24〜40文書は、評価の進め方を探る探索的研究である。票数を独立した標本数として数えない。
- 自動指標は人の結論の補助であり、置き換えではない。フィードバックを保存するだけでは、スキルの動作は変わらない。
- 期待できるのは、改善点の追跡と次の改定判断の質である。改善率は現時点の証拠からは予測できない。

## 目的

日本語の文章生成と編集スキルを人が評価し、そのフィードバックを改定に生かす方法を整理します。調査日は2026-10-16です。効果はまだ測定していません。ツールの選定は[人手評価ツールの選定](001-evaluation-tool-selection.md)の要約を参照してください。

## アプローチ

```mermaid
flowchart LR
  A["人が比較し理由を書く"] --> B["欠陥の種類に分類"]
  B --> C["回帰ケースに追加"]
  C --> D["規則や例を人がレビュー"]
  D --> E["未使用の文書で新旧を比較"]
```

| 評価軸                     | 方法                                 | 注意                                   |
| -------------------------- | ------------------------------------ | -------------------------------------- |
| 意味・事実・条件の保持     | 原文と編集文を編集者に見せる         | 意味変化は総合点に混ぜず、別に記録する |
| 読みやすさ・理解           | 読み手には同じ内容の1版だけを見せる  | 読みやすさの印象は理解の向上を示さない |
| 自然さ・依頼への適合・文体 | 目的、読者、ジャンルを事前に固定する | 子ども向け要約の基準を一般化しない     |

- 比較は「A、ほぼ同じ、B、判断不能」で表す。A/Bの向きと表示順は無作為化し、保存する。
- 単一の出力は「重大な変化、軽微な懸念、確認範囲で問題なし」の3段階で評価する。
- 好みの理由は「どこ」「何が問題か」「なぜ重要か」「どう直すか」を記録する。
- 例: 「条件を満たす場合は申請できる」を「申請できる」にすると、条件の欠落で意味保持が不合格になりうる。これは人工の例であり、測定された事例ではない。
- 主要なジャンル、長さ、編集方式に偏りがないよう24〜40文書を選ぶ。各対を2〜3人が独立に評価する。
- 3〜5件の練習項目で基準を調整し、調整前の記録を本評価のために残す。
- 文書ごとに勝ち、同等、意味保持の失敗率を報告する。各評価者の票は残す。30文書×3人の90票を独立した90標本として扱わない。
- 区間推定には、文書単位で再標本化し、各文書の全評価者の票を残すクラスタブートストラップが最小の選択肢である。
- 一致度は名義尺度と順序尺度のα、単純一致率、ラベルの分布を報告する。単独ユーザーでは一致度を計算せず、「個人の好み」と表す。
- 自動指標は、人が評価する前には見せない。隠すことでスコアによる偏りが減るかは、試験で確かめる。
- 原文・編集文・人の修正・コメントの根拠を、生成条件、スキルの版、評価基準の版と紐づける。
- 類似度が高くても、数値・否定・主語・条件の変化は隠れうる。類似度だけでは意味の保持を保証できない。
- 直接の効果は、改善箇所を追跡しやすくなることである。ただし、入力の負担により、継続参加は減る可能性がある。
- 間接の効果は、フィードバックが規則や例に反映され、未使用の文書で再評価された場合にだけ生じる。ツールそのものは生成文を改善しない。
- 予測を崩す条件は、一人の好みを全読者へ一般化すること、混合ジャンルで1つのスコアを最適化すること、改善データを成果の検証に再利用することである。

## 限界・未確認

- 対象読者、ジャンル、省略してよい情報の範囲は未定義である。
- このツールと日本語の利用者を対象にした実験は行っていない。基準値がないため、改善率、時間、反復回数を予測しない。
- 小規模な試験で有意でない結果は、効果がないことを示さない。
- 区間推定、評価者の効果、自動指標との対応は未検証である。
