# 不足の指摘：Codex による比較計画（Issue #208）

Claude Code の利用枠による中断を受け、Codex で比較を完了します。
旧版・候補版をどちらも生成し直し、Claude Code の19出力は別の記録として保持します。

## 比較条件

- 対象: `gap-note2-run/run.json` に保存した旧版・候補版の全文。
- 件数: ケース18本、反復3回、合計108出力。
- モデル指定: Codex CLI に `gpt-6.1-sol`、推論 `medium` を指定。
- 入力: 同じ依頼・共通指示・スキル全文を各回に渡し、毎回新しいセッションで生成。
- 作業場所: 毎回空の一時フォルダ。サンドボックスは読み取り専用。
- ツール: 外部設定を読み込まない指定とし、生成時の使用を禁止。使用記録がある出力は失敗。
- モデル識別: CLI が解決後の識別子を返さない場合、指定モデルと実行モデルを区別して記録。
- 詳細出力: Git 管理外の `feedback/gap208-codex/` に保存。

## 判定

ケース、語群の判定、採否基準は [元の計画](gap-note2.md) を維持します。
E 群で候補版の効果ありが旧版より6件以上多く、指摘の内容が妥当であることを求めます。
本文だけの依頼への混入、完全な情報への余計な指摘、作り足し、意味の欠落が増えたら採用しません。

語群の判定と内容確認は別に記録します。
内容確認は Codex による確認と明記し、人による確認とは報告しません。
元の計画が求める人による最終確認は、自動実行で満たせない条件として残します。
自動判定だけで不採用条件に該当した場合、その結果を記録して候補規則を外します。

## 限界と終了条件

これは Codex での結果で、Sonnet での改善率を示すものではありません。
自作の短文であり、実利用の効果は未確認です。
API の追加課金には切り替えず、既存の認証を使います。
計画と実行方法のレビュー後に開始し、結果レビュー、採否記録、PR、後片付けまで行います。
数値基準を満たした場合も、人による E 群の妥当性確認と body_gap 全件確認が完了するまで、正式採用・リリース・Mac 更新には進みません。

## 計画レビュー

Antigravity（指定モデル `gemini-4-argon-medium`、推論 `medium`）から条件付き承認を受けました。
人による確認を採用条件として明記し、ツール検出を許可型以外の全アイテムに広げました。
並列処理では成功・失敗を全件回収してから停止し、完了した出力の再生成を避けます。
