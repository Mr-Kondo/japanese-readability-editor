# 任意の小説メモ

長編や継続執筆で必要な欄だけ使う。一場面の依頼に記入を要求せず、管理ファイルを一括作成しない。空欄は未指定であり発明して確定欄へ埋めない。

各記録に必要に応じて「根拠（原稿・章・行） / 確定または暫定 / 対象版」を添える。人物の嘘・誤解や語り手の断言を、客観的な確定事項と分ける。

## 作品メモ

- 作品名・対象版：
- ジャンル・読者に与えたい体験：
- 確定事項（根拠付き）：
- 未確定事項・案：
- 変更禁止事項：

## 文体メモ

- 視点・視点切替の方式：
- 語りの距離・地の文の調子：
- 文のリズム（反復・長文・体言止めなど）：
- 表記（三点リーダー・ダッシュ・句点・字下げ・ルビなど）：
- 人物ごとの口調・一人称・相手による話し方の変化：
- 参照サンプル（原稿・章・行・対象版）：

## 場面メモ

- 時間・場所・視点人物・登場人物：
- 開始時の位置・動作・人物と物品の状態：
- 終了時の位置・動作・人物と物品の状態：
- 依頼された操作・変更範囲：

- 全文を読んだ範囲 / 要約だけを読んだ範囲 / 未読の範囲：
- 今回の新案（未確定）：
