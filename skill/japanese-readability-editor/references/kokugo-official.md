# 公用文の運用(`official`)

適用設定 `official` で追加で確認する、公用文固有の表記・用語の運用をまとめる。選び方は [kokugo-policy.md](kokugo-policy.md) にある。文体が堅いという理由だけでは `official` にしない。公用文の基準に従うことが、依頼や文書の中で示されているときに選ぶ。

## 1. 文書の種類と適用設定

「公用文作成の考え方」は、公用文を種類で分け、種類に応じた書き表し方を認めている(本文 基本的な考え方 1(2)、PDF pp.3-4)。

| 種類(考え方の分類) | 具体例 | 使う設定 |
|---|---|---|
| 法令に準ずる告示・通知等 | 告示、訓令、通達、通知、公告 | `official` |
| 記録・公開資料等 | 議事録、報道発表資料、統計資料、白書 | `official` を基本にし、読み手に合わせて工夫する。用語集で組織の表記を指定し、必要なら `public-explanation` に切り替える |
| 解説・広報等 | 法令・政策の解説、広報、案内、Q&A | `public-explanation` |
| 法令 | 法律、政令、省令、規則 | この skill は検査しない(「法令における漢字使用等について」は未取得) |

## 2. `official` で追加で確認するもの

`general-tech` では許容として扱う表記の一部が、`official` では recommendation または error になる。区分は規則データが決める。

| 確認すること | 規則 ID | `official` の区分 | 根拠 |
|---|---|---|---|
| 副詞・連体詞は原則として漢字(全て、特に、既に など) | `KOKUGO-KANJI-005` | recommendation | 内閣訓令 別紙1(2)イ |
| 接続詞は原則として仮名(かつ、ただし など)。ただし『及び』『並びに』『又は』『若しくは』は漢字 | `KOKUGO-KANJI-003`、`KOKUGO-KANJI-004` | recommendation | 内閣訓令 別紙1(2)オ |
| 補助的な用法・形式的な用法は仮名(ていただく、ことができる など) | `KOKUGO-KANJI-007` | recommendation | 内閣訓令 別紙1(2)カ・キ |
| 表外漢字・表外音訓は原則として用いない | `KOKUGO-KANJI-001`、`KOKUGO-KANJI-002` | needs_context、recommendation | 内閣訓令 別紙1(1)、3 |
| 送り仮名は本則・例外による。許容形は必要な場合に限る | `KOKUGO-OKURI-001`、`KOKUGO-OKURI-002` | recommendation | 内閣訓令 別紙2(1)(2) |
| 読み間違えるおそれのない複合の名詞186語は、送り仮名を省く | `KOKUGO-OKURI-003` | **error**(名詞と確定できる場合) | 内閣訓令 別紙2(1)ただし書 |
| 長音符号を用いて書くのが原則 | `KOKUGO-GAIRAI-001` | recommendation | 考え方 解説 Ⅰ-3エ |
| 『ヴ』をむやみに使わない。第1表・第2表にない表記は原則として使わない | `KOKUGO-GAIRAI-002`、`KOKUGO-GAIRAI-003` | recommendation | 考え方 解説 Ⅰ-3 |
| 算用数字には『○か所』『○か月』 | `KOKUGO-NUM-001` | recommendation | 考え方 解説 Ⅰ-4ケ |
| 句点にピリオドを使わない | `KOKUGO-PUNCT-001` | recommendation | 考え方 解説 Ⅰ-5(1)ア |
| 『するべき』ではなく『すべき』 | `KOKUGO-EXPR-001` | recommendation | 考え方 解説 Ⅲ-1オ |
| 意味が重複する表現(約20名くらい など) | `KOKUGO-EXPR-002` | recommendation | 考え方 解説 Ⅱ-5ウ(ア) |
| 異字同訓の使い分け(選んだ16項目) | `KOKUGO-IJIDOKUN-001` | needs_context | 異字同訓 前書き3 |

現代仮名遣いの明確な誤り(`KOKUGO-KANA-001`〜`003`)は、どの設定でも error である。

## 3. 内閣訓令の適用除外

内閣訓令の別紙3は、次の場合に1・2によらなくてよいとする。`official` でも、次は規則を適用しない(または要確認にとどめる)。

- 固有名詞(人名・地名・組織名)。
- 専門用語または特殊用語を書き表す場合など、特別な漢字使用等を必要とする場合。
- 専門用語等で読みにくいと思われる場合は、必要に応じて振り仮名を用いる等、適切な配慮をする。

固有名詞・専門用語は自動では識別できない。`--glossary` の `protect:` に書くか、`<!-- kokugo-ignore-start -->` と `<!-- kokugo-ignore-end -->` で囲んで除外する。

## 4. 手順

1. 文書の種類を確かめ、設定を決める(上の表)。指定がなければ `general-tech` とする。
2. 組織の用語集・表記指定があれば確認する。公用文の基準と競合するときは、競合を利用者に示す。
3. `check_kokugo.py --profile official` を実行する。
4. `error` を修正する。`recommendation` と `needs_context` は、文脈と読み手を見て決める。
5. 修正した後に、もう一度検査する。

## 5. 注意

- 186語の規則は、動詞に及ばない。「入れ替える」「問い合わせる」「申し込む」のような動詞は本則どおりに書く。「申し込みを」のように直後が『が』『を』『の』のときだけ名詞と確定する。「申し込み、」のように連用形の可能性がある箇所は、要確認である。
- 通則7を適用する語(取扱所、見積書、申込書 など)は、186語に含まれない。直後が漢字の複合語は、要確認にとどめる。
- 告示・通知等の文書で `official` を使うのは、考え方が「法令と公用文における表記を一致させる」としているためである。解説・広報等では、読み手に配慮して送り仮名を省かずに書いたり、仮名で書いたりしてよい。
- `official` は表記の確認である。文体(常体・敬体)の選択、構成、論理の適否は、これまでどおりの診断で扱う。
